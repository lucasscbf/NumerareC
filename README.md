# NUMERARE - Site Institucional Premium

Projeto React + Vite + Tailwind CSS + Framer Motion pronto para rodar localmente e publicar na Vercel.

## Como rodar

1. Instale o Node.js LTS: https://nodejs.org
2. Extraia este ZIP.
3. Abra a pasta no VS Code.
4. No terminal, rode:

```bash
npm install
npm run dev
```

O site abrirá em um endereço parecido com:

```bash
http://localhost:5173
```

## Como publicar na Vercel

```bash
npm run build
```

Na Vercel:
- Framework: Vite
- Build command: npm run build
- Output directory: dist
